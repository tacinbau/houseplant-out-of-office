A make.fun entry: the funniest out-of-office auto-reply a houseplant would send, 120 characters or fewer.

`main.ts` writes the reply to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> Out of office: the fern has unionised. No water since March, no replies until the sunlight negotiations conclude.

Run it with `node main.ts` (Node 22.18+).
